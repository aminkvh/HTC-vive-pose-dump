# Vive Pose Dump
Minimal HTC Vive / OpenVR pose capture tooling with timestamped position and rotation output.

## Status

This repository currently contains an early development build of a minimal Windows pose-dump tool under `minimal_vive_dump/`.

It is still a dev build and may be buggy. Expect rough edges around runtime detection, SteamVR/OpenVR setup, and device-specific behavior until it has been tested on real hardware again.

If you rename the GitHub repository, `vive-pose-dump` is the clearest match for the current app and published Windows bundle.
